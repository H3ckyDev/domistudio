# DomiStudio (domistudio.cl) 🚀

Landing page profesional construida con **Astro 5** y **Tailwind CSS**, diseñada fielmente a partir del concepto visual con tres pilares esenciales: **Diseño**, **Desarrollo** y **Soporte**.

---

## 🎨 Características de Diseño & UX

1. **Replicación exacta de las 3 tarjetas de servicio:**
   - **✨ Diseño:** *"Ideas que se ven increíbles"* — Mockup de laptop MacBook en perspectiva con tienda de café artesanal ("Good Coffee Good Mood."), chispas decorativas y botón interactivo "Ver más".
   - **</> Desarrollo:** *"Tecnología para hacer crecer tu negocio"* — Manchas orgánicas chocolate oscuro, ventana de editor de código con sintaxis resaltada (`<DomiStudio />`), columna flotante con iconos de React, JavaScript y Base de datos, y pill 3D con `</>`.
   - **🎧 Soporte:** *"Acompañamiento en cada etapa"* — Audífonos de estudio matte cream con micrófono, tarjeta flotante *"Tu sitio siempre en línea"*, y los 3 pilares inferiores (*Respuesta rápida*, *Soluciones confiables*, *Tu proyecto siempre en foco*).
2. **Animaciones Profesionales:**
   - Efecto **Tilt 3D interactivo** en las tarjetas al mover el cursor.
   - Flotación suave (*gentle float*) en insignias y elementos decorativos.
   - Transiciones de elevación y sombras multicapa en hover.
   - Navegación responsive con menú móvil y header con efecto de desenfoque de cristal (glassmorphism).
3. **Secciones completas de Landing Page:**
   - **Hero** con métricas de confianza y propuesta de valor orientada a Chile.
   - **Pilares de Servicio** (sección central idéntica a la imagen de referencia).
   - **Sobre DomiStudio** con métricas de Google Core Web Vitals (100/100).
   - **Metodología** paso a paso (Estrategia, Creatividad, Ingeniería, Respaldo).
   - **Portafolio** seleccionado de clientes.
   - **Testimonios** verificados.
   - **FAQ** interactivo con acordeones desplegables.
   - **Llamado a la acción (CTA)** con botón directo a WhatsApp y correo.
   - **Footer completo** con identidad de marca para `domistudio.cl`.

---

## 🛠️ Tecnologías

- **[Astro](https://astro.build/)** v5 (Arquitectura estática ultra veloz, cero sobrecarga)
- **[Tailwind CSS](https://tailwindcss.com/)** (Sistema de diseño y paleta cálida: cream, café latte y chocolate espresso)
- **HTML5 Semántico & SVG Vectoriales** (Ilustraciones y mockups nítidos en cualquier resolución)

## 💻 Comandos para ejecutar localmente

```bash
# Navegar al directorio
cd C:\Users\hecto\.gemini\antigravity\scratch\domistudio

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Previsualizar el build de producción
npm run preview
```
